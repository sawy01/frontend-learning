# Playing Cards with Flexbox

 This is a small project located in my experiments folder. The goal was to practice using CSS Flexbox to align items inside a fixed container—specifically, making realistic playing cards.
 
 🎯 The Goal
 
  I wanted to see if I could recreate the layout of a real playing card using only HTML and CSS. This helped me practice:
- Placing items in corners (Top-left and Bottom-right).
- Centering large symbols perfectly in the middle.
- Using flex-wrap to create the patterns for the "6" and "4" cards.

 🛠️ What I Learned
 
- The Power of justify-content: space-between: This made it easy to push the card rank (the number) to the top and bottom.
- Rotation: I learned how to use transform: rotate(180deg) to flip the bottom rank upside down, just like a real card.
- Hover Effects: I added a simple scale effect to make the cards feel interactive when you hover over them.
- Troubleshooting: I learned that if my font-size is too big or my gap is too wide, the content will break out of the card. I had to balance these to keep everything looking neat.

 🃏 Cards Included
- Ace of Spades (Large centered symbol)
- King of Hearts (Red color practice)
- Six of Clubs (Flex-wrap layout practice)
- Four of Diamonds (Grid-like flex practice)
